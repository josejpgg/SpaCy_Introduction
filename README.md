# SpaCy_Introduction

##### ESP

Primer proyecto practico para resolver la actividad 1 del curso de Procesamiento de Lenguaje Natural.

Se toma como fuente de datos un corpus con comentarios catalogos como comentarios con odio y sin odio.

Los ejercicios del notebook son en base a identificar caracteristicas para esta clase de comentarios.

##### ENG

First practical project to complete Activity 1 of the Natural Language Processing course.

A corpus of comments categorized as hateful and non-hateful is used as the data source.

The exercises in the notebook are based on identifying characteristics for this type of comment.
